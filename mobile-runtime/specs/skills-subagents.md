# 移动端 Skills 与 Subagents

技能和子代理的列表、启停及资料写入仍由对应设置服务拥有；Agent 每轮从同一服务读取当前工作区的快照，设置与运行时不得各自维护状态。仅已启用的技能出现在模型可用目录，用户显式 `$name` 引用时在本轮注入对应正文；`Skill` 工具可按目录名称加载正文，路径仅来自发现结果，禁止模型自行提供路径。技能正文过长时明确标注截断。

`Agent` 工具调用已发现并启用的 profile，在独立 transcript 中运行真实模型循环；模型选择、profile 指令、工作目录、工具白名单、显式禁用工具、技能和最大轮数必须生效。父轮的执行模式和终止信号持续约束子代理：计划模式禁止写操作，子代理的每次工具调用都进入父 Agent 的 Hook、工作区授权与人工审批入口，不得直接调用一个绕开这些入口的执行器。工具返回的真实内容进入子代理下一次模型请求；完成、失败和取消必须准确传回父轮的工具结果。未能满足 profile 的依赖必须报错，不能忽略配置后报告成功。

移动首版只支持前台、单层子代理；后台执行、跨轮续接及进一步派生目前明确拒绝，UI 和工具描述不能宣称已支持。自定义工具模式不受支持时拒绝该 profile，不把模式误读成无条件的完整工具授权。带独立 MCP server 配置的 profile 在专用运行时接入前明确报错；从父会话继承的已注册工具可以按 profile 白名单使用。

```text
设置服务 → 每轮 profile/skill 快照 → Agent 工具 → 独立子 transcript → 模型
                                                   ↓ tool call
                                      父 Agent Hook → 模式与授权 → 工具执行 → 子 transcript
                                                   ↓
                                    完成/失败/取消 → 父轮工具结果
```

验收包括：真实目录发现和启停、显式技能与 Skill 调用、重复名拒绝、子代理 profile 与模型选择、工具结果回传、工具白名单及计划模式、拒绝和取消、异常/空响应及不可用配置。能力调用无运行时或无法完成时必须如实报告。

工作区 profile 的启停标识必须包含工作区路径，两个目录下同名 profile 不能共用状态。编辑和删除只允许操作服务最近实际发现或创建的、身份与路径一致的 profile；写入与删除前验证所属的用户或工作区 agent 根及路径中的符号链接，不接受请求自行指定任意旧文件路径。缺少可信发现记录时拒绝修改并要求重新加载列表。

技能复制需要实际复制技能目录的文件树；移动端对包含符号链接的目录明确拒绝，避免复制时跨越授权边界。通用目录移除须使用受边界约束的技能删除逻辑，不能使用子串匹配路径。
