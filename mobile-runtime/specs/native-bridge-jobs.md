# Android 执行和 HTTP 桥

原生桥负责拥有每次请求的任务及其取消状态；JS 调用者只保存任务 ID，按短间隔读取结果，不在 WebView 的 JavaScript 线程等待命令或网络。单个任务的时序为 `start → poll* → result`，取消可以在启动前、运行中或完成前发生；结果至多被取走一次。完成后无人读取的结果允许超时清理，不能泄漏凭据。旧宿主只提供同步 `exec`/`call` 时继续保留兼容调用。

- 命令的 stdout、stderr 与 stdin 并行处理；没有 stdin 时也必须关闭输入管道，超时从进程启动后开始计算，取消或超时结束进程并返回对应状态。
- HTTP 手动处理重定向：禁止非 HTTP(S) URL，禁止 HTTPS 降级为 HTTP；跨源重定向删除身份凭据和 Cookie 等敏感请求头，且不能重新附加。结果或取消后释放连接。
- 主 WebView 只允许应用资产作为文档导航；外部 frame 被拦截，外部主页面链接交给无原生桥的浏览器或系统浏览器，模型等 HTTP 请求仍可正常发生。
- 旧接口继续用于自检及旧宿主；新增 JS 调用方优先使用异步协议并透传取消信号。

验收覆盖：输入 EOF、并发大输出、超时和取消；异步等待时事件循环可运行；重定向敏感头策略；非可信页面无法在主 WebView 加载；无桥时返回结构化失败。
