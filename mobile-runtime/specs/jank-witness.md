# 冻结证人（jank witness）

- 主线程冻结用 200ms 心跳的**相邻回调间隔**判定：gap ≥800ms 记一次冻结，落盘时间戳、堵了多少毫秒、当时在跑什么。正常 GC 与渲染抖动够不到这条线。
- 后台停留不计为冻结：切到后台停心跳，回前台从当前时刻重新起算（系统节流与后台冻结不是 UI 卡死）。
- 冻结归因的 phase 取**内存里的当前标注**：工具执行前后标注 `tool:<name>`，冻结样本落盘时带上它；标注不必逐次落盘。
- phase 标注按 1 秒节流落盘：工具执行的热点路径上每次至少标两次，逐次落盘等于每次标注一次同步 localStorage 写——证人自己不能成为卡顿的一部分。
- 桥族计时壳默认关（`localStorage["zcode-mobile.jank.shell"]="1"` 重启才开）：开启后按族×操作记次数、总耗时、最慢单次，单次 ≥400ms 立刻落盘。
- 计时壳对原生桥**无副作用**：方法一律 bind 回宿主对象，receiver 语义不变；装壳后用无副作用探针验活，探针抛异常立刻回退成原全局。证人绝不弄挂数据通道。
- 证人表覆盖全部同步原生桥族：fs/tree/sqlite/exec/browser/device/githttp/model。model 是原生模型流桥——模型响应逐块在 UI 线程上同步 poll，不在表里就归因不到它。
- 读数只有一份：`localStorage["zcode-mobile.jank.diag"]` 同时装冻结样本、桥计数与最慢单次，自检报告一条读数即可回答"堵了多久、堵在哪一下"。
- 验收：Node 侧冒烟（`build/jank-witness-smoke.mjs`）覆盖装壳透明、计数形状、慢调用落盘、心跳 gap 归因、后台不误记、模型桥入表与 phase 节流。
