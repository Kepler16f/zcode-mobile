# 移动 Git 面板

Git 仓库和工作树由 isomorphic-git 与同一份移动 VFS 持有。面板读取和写入当前工作区根目录的仓库，不跨越到父目录；无法可靠完成的操作明确返回错误。SAF 工作区在镜像访问和写回能够共享完整事务前，面板和 Git 工具均保持不可用。

面板提供仓库状态、分支、提交历史、文件变更、文本 Diff、暂存/取消暂存和提交。路径必须在工作区内；切换分支不得强制覆盖改动。丢弃、远程推送和模型生成提交信息在对应端口未接入时返回明确错误，不伪造成功或空结果。

验收包含真实本地仓库的干净状态、文件改动、暂存、取消暂存、提交、分支切换，以及越界路径和非仓库行为。界面和 Agent 共用同一份仓库文件作为事实来源。

状态以 HEAD、index 和工作树的 blob OID、文件类型及有效 mode 为准。工作树必须读取内容重新 hash，不能把 statusMatrix 或 index 的 stat 缓存当成最终事实，以覆盖同秒同尺寸修改。index 的内容由其 OID 读取对象；HEAD 由 TREE walker 解析。未跟踪文件遵守 ignore，已跟踪文件不受 ignore 隐藏。同文件可以同时有暂存与未暂存改动。

暂存差异比较 HEAD → index，未暂存差异比较 index → 工作树。文本行数来自同一份有界差异算法，生成标准 unified patch，新增/删除使用 /dev/null，保留末尾无换行标记，CRLF 预览统一为 LF，末尾换行不额外算空行。二进制明确返回 binary，任一侧超过 1 MiB 或计算超出预算返回 truncated；非 blob 对象明确不可预览。空仓库、新增空文件、删除和 mode 改动都保留状态；无法统计的项目行数为 0，与桌面二进制统计约定一致，不生成假 patch。

验收补充：暂存新增/删除、工作区删除、未跟踪与忽略文件、同文件两种改动、同秒同尺寸修改、真实增删行数、EOF 换行、二进制、超过 1 MiB、空仓库，以及 .git 和越界路径拒绝。

差异预算同时限制总行数（两侧合计 50,000 行）、Myers 回溯单元和迭代次数；小于字节上限但包含海量短行的文本也必须降级，避免主线程大量分配。

## Git 边界和一致性

- 面板和 Agent 的 `status` 必须共享同一组三树扫描语义，不能让同秒同尺寸修改在不同入口呈现相反结果。变更行必须区分已暂存和未暂存；忽略规则不得隐藏已跟踪文件。
- Git 的所有文件 I/O 限制在当前仓库根目录内；路径词法越界、跨工作区符号链接、指向外部的 `.git` 文件和不安全的远端树条目不得通过 Git 命令访问或写入工作区外的文件。目标路径检查必须覆盖文件系统操作本身，而不仅依赖模型传参检查。目录符号链接明确拒绝；Git 链接条目无法由宿主处理时如实失败。
- `add` 的 `path` 是单个完整相对路径，允许空格；批量使用 `paths` 数组。目录与 `.` 均包含已跟踪文件删除，所有路径先校验再修改索引。不存在且未跟踪的路径报告错误。Git push 返回失败时不能报告已推送；远端地址带凭据时展示和错误不得暴露密码。
- 提交只提交用户请求的范围：选择文件时有未选中的暂存变更必须拒绝；未选择时默认提交暂存内容。缺失 Git 历史以外的日志读取失败不能伪装为空历史。对同一分支切换须如实报告没有变化。
- SAF 镜像若未准备好或回写失败，Git 结果必须明确失败；镜像不具备完整性和跨入口事务保障时不应声称操作已安全完成，优先使用本地文件夹。
- 现有 SAF staging 没有完整性及跨入口互斥保证，因此 Git 面板和 Agent 均拒绝对其执行 Git；将来只有 staging 明确提供这两项保证并声明 `transactionSafe` 才允许启用。clone 子目录必须为空，避免覆盖现有文件。
- clone 和 remote 新保存的仓库 URL 不得包含用户名或密码；嵌入的认证信息只用于本次网络请求的认证回调，后续请求显式提供凭据。禁止带查询串或片段的远端地址，以免令牌进入配置；错误与响应不得泄露凭据。已有含用户名或密码的远端保持原配置，展示时脱敏，网络请求临时使用去除凭据的 URL 和认证回调，避免查看远端时破坏用户现有配置；已有带查询串或片段的远端须提示用户重新配置。

验收覆盖 Agent 与面板同秒同尺寸修改的一致性、暂存删除、带空格路径、多路径预检、词法越界、目录和 `.git` 符号链接越界、恶意 Git 目录、推送拒绝和凭据脱敏、未出生仓库日志、真实故障与同分支切换。不得向外部远端执行测试推送。
