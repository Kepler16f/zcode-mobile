# 0.9.1 二次复查

- 原生 `localTreeAliases` 仅返回主存储卷同一真实目录的路径别名，并非副本。文件与 Git 写入只执行一次；别名不得触发 SAF 二次写入或 staging 镜像。追加、重命名、删除均须从两种路径读到一致结果。
- 无凭据桥时仍注册公开套餐预览服务，且不得将它列入 `stubbed`；领取、余额和消费仍依据真实凭据及服务端资格。
- 用量投影读取跨事件循环时，必须检测源记录版本变化，不能拼接新旧 JSON 或用旧读取覆盖收轮后的新投影。保存版本须单调且仅在写入成功后推进。
- 启动早期异常必须撤下启动遮罩并展示可重试错误；自检入口默认隐藏。

所有者与时序：`agent 收轮 → session store 保存主记录 → 保存同版本用量投影 → 统计读取按版本校验`。统计迁移只在源版本未变化时发布投影。
