# 移动工作区选择与隔离

用户选择的目录是本次工作区的唯一根。Android 外部主存储目录在系统允许直接访问、目录存在且可读取时优先返回真实本地路径，文件工具、Git 和命令工作目录均使用同一目录。没有系统授权、路径无法可靠还原、或者目录来自不支持直接路径的存储提供方时，保留用户已有的 SAF 工作区及其授权，不把无法访问的路径伪装成真实路径。改变工作区不会迁移已有会话，已有会话只能通过其所属的工作区访问和执行。

```text
用户选择目录 → 本地路径（可访问时）/ SAF 挂载 → 工作区身份与路径
   → 会话绑定 → 会话独立工具引擎 → 文件端口校验 → 同一后端读写
                                  └→ 越界：已有权限交互 → 单次或该会话授权
```

系统的全部文件访问权限只决定原生后端能否访问共享存储，不自动扩大 Agent 的工作区。所有文件操作（含读取、写入、搜索、删除和下载）先验证词法路径及符号链接目标；工作区之外须经过现有授权流程。`/sdcard`、`/storage/emulated/0`、`/storage/self/primary` 和已有 `/ext` 为同一主存储的路径别名，比较权限时规范化，不能利用别名绕过根检查；其他存储卷仍独立判断。授权仅属于发起会话，单次授权在调用完成后撤销，不泄漏到同工作区其他会话。

搜索必须对每个被读取的文件检查符号链接，目录扫描不得跟随指向根外的链接；只删除符号链接本身时不能误删其目标。会话重启恢复、命令、订阅、附件和快照请求遇到不匹配的工作区一律拒绝，不因缓存命中或幂等命中而绕过校验。无工作区参数的既有只读协议按全局唯一 sessionId 查询。

原生命令运行在 Android 应用自身的权限下，不具备能限制任意 shell 命令访问范围的系统沙箱；普通模式继续保留命令审批，完全访问模式遵守用户选择。不得声称 Bash 一定被文件端口围栏约束。SAF 镜像是遗留兼容路径，失败时不得静默把缺失文件当成真实空文件，也不得用残留镜像回写覆盖授权树。

验收覆盖：两个同时打开的工作区、重启恢复、重复命令、两个会话的单次与长期授权、主存储路径别名、`..`、根外绝对路径、目录及文件符号链接、搜索批量读取、删除链接、下载授权与撤销、目录选择权限与不可访问的 SAF 退路。

SAF 镜像无法保证读取完整或防止外部并发写入，Bash 和 Git 暂时拒绝运行于 SAF 工作区；文件工具仍直接操作授权目录。
